## About

Hi, I'm Hafiz, a frontend and mobile developer from Indonesia. I build interfaces for the web with React and for phones with Flutter, and I care about the small details that make an app feel easy to use.

Most of what I make starts as a small idea I want to see working. I'd rather ship a rough version and keep improving it than wait for it to be perfect, which is where my motto comes from. Right now I'm learning C++ to strengthen my programming fundamentals.

> Always shipping something, even if it's small.

## Projects

<h4><a href="https://github.com/hafizarya326/studystreak">StudyStreak</a></h4>

A study timer that makes coming back every day feel rewarding. It combines a Pomodoro timer with a daily streak system, achievements and honest statistics.

- Pomodoro, short break, long break and custom timers, with timing that stays accurate across tab switches and refreshes
- Streak tracking in the user's local timezone, with streak freezes and achievements
- Activity heatmap, weekly and monthly charts, and light and dark themes

> React · TypeScript · Vite · Tailwind CSS

[Live demo ↗](https://studystreak-eight.vercel.app) &nbsp;·&nbsp; [Source code](https://github.com/hafizarya326/studystreak)
