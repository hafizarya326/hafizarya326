<h2 align="center" id="about-me">About Me</h2>
Hi, I'm Hafiz Arya, a Frontend and Mobile Developer from Indonesia. I enjoy building applications that are genuinely useful: interfaces that are clean, responsive, and pleasant to use, whether they live in a browser or on a phone.
I'm passionate about the full path from an idea to something people can actually open and use. That means paying attention to UI/UX details, writing readable code, and treating every project as a chance to get a little better at software engineering. I like learning new technologies, and I'm currently adding C++ to my toolbox to strengthen my programming fundamentals.
